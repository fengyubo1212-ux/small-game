# 小游戏平台 - 游戏大厅设计文档

**日期：** 2026-07-28
**状态：** 已确认

---

## 1. 概述

将当前单游戏 `index.html` 改造为多页面游戏平台。`index.html` 作为游戏大厅首页，每个小游戏为独立 HTML 文件。平台名称："小游戏合集"。

## 2. 架构

```
index.html          ← 游戏大厅（首页）
match3.html         ← 图片消消乐（从 index.html 拆分）
games/              ← 新游戏存放目录
  └ (预留)
```

### 导航关系

```
index.html ──点击卡片──→ match3.html
match3.html ──返回大厅──→ index.html
```

## 3. 大厅页面设计（index.html）

### 布局（手机竖屏）

```
┌──────────────────────────────┐
│       🎮 小游戏合集           │  ← 顶部标题栏
│                              │
│  ┌──────────┐ ┌──────────┐  │
│  │  封面图   │ │  敬请     │  │
│  │          │ │  期待     │  │
│  │ 图片消消乐│ │          │  │  ← 2列卡片网格
│  └──────────┘ └──────────┘  │
│  ┌──────────┐               │
│  │  敬请     │               │
│  │  期待     │               │
│  └──────────┘               │
└──────────────────────────────┘
```

### 卡片设计

- **已有游戏卡片：**
  - 封面图（使用消消乐棋盘截图或 test1.jpg 作为封面）
  - 下方显示游戏名称"图片消消乐"
  - 可点击，跳转到 `match3.html`
  - hover/点击有轻微缩放效果

- **占位卡片：**
  - 灰色背景 + "🔜" 图标
  - 下方显示"敬请期待"
  - 不可点击，无交互

### 配色

- 背景：沿用浅紫→浅蓝渐变（与消消乐保持一致）
- 卡片：白色底，圆角 16px，轻微阴影
- 标题：深色粗体

## 4. 消消乐页面改动（match3.html）

### 从 index.html 拆分

将当前 `index.html` 的全部内容移动/重命名为 `match3.html`。

### 顶部添加返回按钮

```
┌──────────────────────────────┐
│  ← 返回大厅                   │  ← 新增返回栏
├──────────────────────────────┤
│       🏆 第 1 关              │
│   分数: 0 / 100              │  ← 原有游戏界面不变
│   ...                        │
└──────────────────────────────┘
```

- 返回按钮：左箭头 + "返回大厅"文字
- 点击跳转到 `index.html`

## 5. 技术实现

- 全部纯 HTML/CSS/JS，零依赖
- 页面间通过 `<a href>` 或 `location.href` 跳转
- 文件结构：
  - `index.html` — 新建，游戏大厅
  - `match3.html` — 从当前 `index.html` 重命名而来，顶部加返回栏
  - `games/` — 新建空目录，预留
  - `test1.jpg, test2.jpg, test3.jpg` — 保持不变（消消乐引用）

## 6. 扩展流程（未来加新游戏）

1. 创建 `games/新游戏.html`
2. 在 `index.html` 卡片列表中增加一张可点击卡片
3. 完成
