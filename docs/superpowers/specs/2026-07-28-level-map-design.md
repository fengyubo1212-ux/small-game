# 图片消消乐 - 关卡地图设计文档

**日期:** 2026-07-28
**状态:** 已确认

## 1. 概述

match3.html 增加关卡地图作为进入游戏前的准备界面。蛇形路径展示所有关卡，已通关/当前关/未解锁三态，点击当前关进入游戏。

## 2. 页面架构

match3.html 改为双视图：
- **地图视图**（默认显示）：关卡路径地图
- **游戏视图**（点击关卡后显示）：原有消消乐游戏界面

两个视图用 CSS display 切换，不需额外文件。

## 3. 地图布局

- 顶部：←返回大厅 + 最高关卡记录
- 中央：蛇形路径，节点从上到下排列
- 底部：简短玩法说明
- 关卡节点三态：已通关(绿+✅)、当前关(金+🔥+呼吸)、未解锁(灰+🔒)
- 当前关节点 56px 放大 + pulse 动画
- 可滚动，显示所有已解锁+若干未解锁关卡
- 点击当前/已通关关卡 → 切换到游戏视图

## 4. 进度系统

- localStorage 存储 `match3_max_level`
- 过关后更新 max_level = max(max_level, level + 1)
- 地图根据 max_level 渲染节点状态
- 点击已通关关卡可重玩

## 5. 游戏视图改动

- 顶部添加"← 关卡地图"返回按钮（替换当前"返回大厅"）
- 游戏逻辑不变

## 6. 技术实现

- HTML/CSS/JS 单文件 match3.html
- 双视图切换
- CSS @keyframes pulse 呼吸动画
- localStorage 持久化进度
