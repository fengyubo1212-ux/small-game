# 图片消消乐（三消型）设计文档

**日期：** 2026-07-28
**状态：** 已确认

---

## 1. 概述

手机端三消小游戏，使用 3 张本地照片（test1.jpg, test2.jpg, test3.jpg）作为方块图案。
纯前端单 HTML 文件，零依赖，微信/浏览器直接打开即玩。

## 2. 游戏规则

| 项目 | 规则 |
|------|------|
| 棋盘 | 6×6 网格，共 36 格 |
| 方块类型 | test1.jpg / test2.jpg / test3.jpg 对应 3 类 |
| 操作 | 触摸拖拽交换相邻方块 |
| 消除 | 横向或纵向 ≥3 个同类型连续则消除 |
| 模式 | 目标分数闯关，限制步数 |
| 死局 | 无相邻可消除对 → 直接失败 |
| 过关 | 达到目标分数 → 下一关 |
| 失败 | 步数耗尽未达标 或 死局 → 重新开始 |

## 3. 计分系统

**基础分：**

| 消除数量 | 得分 |
|----------|------|
| 3 | 10 |
| 4 | 20 |
| 5 | 40 |
| 6（整行/列） | 80 |

**连击（Combo）：** 一次交换后，消除→下落→填充过程中自动触发的新消除计为连击。
- combo 从 1 开始（首次消除 combo=1）
- 总得分 = 基础分 × combo 数
- 例如：3连消(10)后下落触发新3连消 → 10×1 + 10×2 = 30 分

## 4. 难度曲线

| 关卡 | 目标分 | 步数 | 说明 |
|------|--------|------|------|
| 1 | 100 | 20 | 教学关 |
| 2 | 200 | 20 | 熟悉节奏 |
| 3 | 350 | 18 | 开始收紧 |
| 4 | 500 | 18 | |
| 5 | 700 | 16 | 需要连击 |
| 6 | 900 | 16 | |
| 7 | 1200 | 15 | 考验策略 |
| 8 | 1500 | 15 | |
| 9 | 1800 | 14 | |
| 10+ | 2000+(n-10)×300 | max(10, 14-⌊n/5⌋) | 公式自动生成 |

步数最低 10 步，不再减少。

## 5. 状态机

```
IDLE → 玩家拖拽 → SWAPPING → 消除判定
  ├─ 无消除 → 换回（扣1步） → IDLE
  └─ 有消除 → 消除动画 → 下落填充 → 再判定（连击循环）
       └─ 无更多消除 → 状态检查
            ├─ 达标 → 过关弹窗
            ├─ 未达标+有步数 → IDLE
            ├─ 未达标+无步数 → 失败弹窗
            └─ 死局 → 失败弹窗
```

## 6. 数据结构

```js
board: number[][]        // 6×6，值 0/1/2 对应三张图片
state: {
  level: number,         // 当前关卡
  score: number,         // 当前分数
  target: number,        // 目标分数
  stepsLeft: number,     // 剩余步数
  comboCount: number,    // 当前连击数
  gameStatus: string,    // 'idle' | 'swapping' | 'animating' | 'win' | 'lose'
  selectedCell: {r,c}|null,
}
```

## 7. 核心函数

| 函数 | 职责 |
|------|------|
| `initBoard()` | 生成无初始三连的随机棋盘 |
| `swap(r1,c1, r2,c2)` | 交换两个相邻格子 |
| `findMatches()` | 扫描行列，返回所有 ≥3 连续匹配 |
| `removeMatches(matches)` | 消除匹配块 + 加分 + 连击计数 |
| `applyGravity()` | 上方方块下落填补空位 |
| `fillBoard()` | 顶部空位填充随机新方块 |
| `checkDeadlock()` | 遍历所有相邻交换，判断是否存在可消除对 |
| `getLevelConfig(n)` | 返回第 n 关的目标分和步数 |

### 交互反馈

- **选中**：方块轻微放大 + 边框高亮
- **拖拽**：方块跟随手指，原位留半透明残影
- **消除**：缩小+淡出，0.2s
- **下落**：新方块从顶部滑入，0.3s ease-in
- **连击**：中央弹出 "COMBO ×N!"，0.4s 后消失
- **弹窗**：半透明遮罩 + 白色卡片居中（过关/失败）

## 9. 技术实现

- 单文件 `index.html`，包含内联 CSS + JS
- 三张图片与 HTML 放在同一目录，`<img>` 直接引用
- 触摸事件：`touchstart` → `touchmove` → `touchend`，计算滑动方向触发交换
- 动画：CSS transition（transform, opacity），不用 JS 动画库
- 无需任何构建工具或后端
